The Scope section
User-curated, machine-assisted. The builder proposes chips parsed from experience bullets; the user promotes, edits or rejects them. All 23 Scope rows across the template set are now count-agnostic — this page is the render contract for the Jinja port.
01 Schema
Keep metric a string. "$4.1M", "95%" and "2×" carry formatting the user chose. Storing 4100000 and formatting at render means owning currency, locale and rounding decisions you do not need to own.
achievements: [ { metric: "$4.1M", label: "Budget owned" }, { metric: "12", label: "Team led" }, { metric: "9", label: "Markets" }, { metric: "95%", label: "Retention" } ]

03 Jinja
{%- set chips = achievements | selectattr("metric") | list | batch(4) | first -%} {%- if chips -%} <div class="cv-scope" style="display:grid; grid-auto-flow:column; grid-auto-columns:minmax(0,1fr); gap:18px; border-top:1px solid #16161A; border-bottom:1px solid #D6D6DA; padding:16px 0;"> {%- for c in chips %} <div class="cv-scope-chip"> <div class="cv-scope-metric">{{ c.metric }}</div> <div class="cv-scope-label">{{ c.label }}</div> </div> {%- endfor %} </div> {%- endif -%}
selectattr("metric") drops empty chips before the count is taken, so the column count is always the surviving count. batch(4) | first caps the render at four — five breaks the row on every template in the set.

05 Content rules for the builder
Mix the kinds
Budget, team and markets are scope; retention is outcome. Scope says how big the seat was, outcome says whether the person was good in it. An all-scope row reads as a job description.
Corroborate
Every chip must reappear in an experience bullet. Recruiters look for the figure a second time, and this is the most commonly inflated element on any CV. Sourcing chips from bullets satisfies this by construction.
Real text
Number and caption are selectable text, never baked into a graphic and never ::before { content }. Pseudo-element content does not exist for a converter or an ATS parser.
Seniority tell
Craft-output metrics — "847 mockups", "300 tickets closed" — signal the wrong level on a leadership CV. Reject them at input, not at review.
