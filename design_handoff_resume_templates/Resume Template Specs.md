classes to resolve. Jump to any one by anchor, e.g. `#t7`.

document referring to a different number is stale — this file and the coded HTML are

## Invariants held across all 24

Enforced during the audit; these are the acceptance gates for the port. Full
checklist in `brief-compliance-checklist.md`.

- **Page box** — exactly 850×1100px, `box-sizing:border-box`, verified `scrollHeight === 1100` with zero element overflow.
- **Skill levels are text** — every bar, ring and dot row carries the skill name *and* its level as real selectable text. Never colour or shape alone.
- **No content in CSS** — no `::before { content }`, no text baked into a background image.
- **True siblings** — repeating entries share identical structure. No specially-styled first or last entry.
- **Scope rows are count-agnostic** — columns derive from the surviving chip count. See `Scope Section Spec.html`.
- **Placeholder content only** — no real person's data, no sample copy carried from any reference image.

## Ring templates and Word export

Several directions render skills as conic-gradient rings. `conic-gradient` has no
python-docx equivalent. The documented switch is **rings in HTML, dot-grid in Word**
(5 dots: Foundational 2 / Proficient 3 / Advanced 4 / Expert 5), with the skill name
and level word as real text in both. The affected blocks carry an inline `docx:`
comment in the HTML marking the swap point — search the file for `docx:` to find them.
